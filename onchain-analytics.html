Ethereum On-Chain Analytics

A practical analysis of Ethereum transaction behavior, gas consumption and network activity using Python, SQL, DuckDB, Pandas, Matplotlib and public AWS blockchain data.

02. Objectives and questions

  • How does Ethereum transaction activity change by hour and day?
  • What proportion of transactions succeed or fail?
  • How do transaction types and gas metrics differ?
  • How do daily transaction counts relate to unique sending addresses?
  • Can unusual changes in transaction and sender activity be identified?

03. Data and technology

Data provider: AWS Public Blockchain Data

Blockchain: Ethereum

Storage format: Apache Parquet (.snappy.parquet)

Query approach: DuckDB reads publicly available data in Amazon S3; AWS credentials are not required for the public files used.

Technology stack: Python, Pandas, DuckDB, SQL, Matplotlib, Jupyter Notebook, AWS S3, Git and GitHub.

05. Correlation and anomaly detection

Transaction volume and unique sending addresses showed a strong positive correlation of +0.859 during the observed period. Correlation describes association; it does not establish causation.

A rolling seven-day Z-score method with an absolute threshold of at least 2 was used to flag unusual daily activity.

DateTransaction volumeUnique senders

October 25 showed an unusual decline in both measures; October 28 showed an unusual increase in unique sending addresses.

07. Reproducibility and project resources

The repository contains five Jupyter notebooks, CSV analysis outputs, visualizations, a 30-day report, requirements and setup instructions. The raw Parquet data is not stored in the repository; the AWS analytics notebooks query public S3 data and therefore require internet access.

Repository → Analysis notebooks → All visualizations → 30-day report →
Limitations

A unique sending address does not necessarily represent one individual user. Correlation does not establish causation, and the anomaly threshold is exploratory. The current network activity analysis covers a 30-day observation period.
