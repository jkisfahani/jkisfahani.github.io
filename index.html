01. About Me

I work on practical data analytics and blockchain research projects, using Python, SQL and DuckDB to explore real-world datasets and communicate findings through clear visualizations. I am particularly interested in data quality, measurable insights and reproducible analysis.

02. Featured Projects

● Research Project

Ethereum Wallet Security Transparency

A structured review of 31 public security-evidence records across eight Ethereum wallets, covering audits, bug bounties, disclosures and wallet-specific documentation. The analysis distinguishes direct wallet evidence from component and ecosystem-level claims; it is an evidence review, not a wallet safety ranking.

View Project Details GitHub Repository
● Analytics Project

Ethereum On-Chain Analytics

An analysis of 53.7 million Ethereum transactions over 30 days using Python, SQL, DuckDB and public AWS data. It examines network activity, gas usage, transaction failures and unusual changes in daily transaction and sender activity.
