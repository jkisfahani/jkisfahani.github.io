02. Featured Projects

● Forecasting & Deep Learning Project

Ethereum Network Activity Forecasting (2015–2026)

A comparative forecasting study using 4,066 daily Ethereum transaction-count observations from 1 October 2015 to 17 November 2026. It evaluates naïve and seasonal-naïve benchmarks, ARIMA/SARIMA, Random Forest, XGBoost, MLP and LSTM using chronological data splits. LSTM achieved the lowest final-test errors among the four machine-learning and deep-learning models evaluated.

● Time-Series Analytics Project

Ethereum Monthly and Quarterly Time-Series Analysis (2015–2026)

A long-term analysis of Ethereum blockchain transaction activity from 2015 to 2026. The project examines monthly and quarterly trends, growth, seasonality, structural changes, time-series properties and forecasting using Python and statistical methods.

View Project on GitHub
● Research Project

Ethereum Wallet Security Transparency

A structured review of 31 public security-evidence records across eight Ethereum wallets, covering audits, bug bounties, disclosures and wallet-specific documentation. The analysis distinguishes direct wallet evidence from component and ecosystem-level claims; it is an evidence review, not a wallet safety ranking.

View Project Details GitHub Repository
● Analytics Project

Ethereum On-Chain Analytics

An analysis of 53.7 million Ethereum transactions over 30 days using Python, SQL, DuckDB and public AWS data. It examines network activity, gas usage, transaction failures and unusual changes in daily transaction and sender activity.
